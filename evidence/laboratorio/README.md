# Evidencia Windows Server: pendiente de ejecución

Esta carpeta no contiene resultados de IIS, ARR, AD DS ni del laboratorio universitario.
El `.gitignore` evita publicar automáticamente inventarios con nombres/IP reales, configuraciones y logs. Después de revisar y anonimizar, agrega sólo los archivos elegidos con `git add -f evidence/laboratorio/archivo`.

Cada ensayo debe conservar: identificador, fecha UTC, responsable, plataforma, versiones, parámetros de carga, configuración de health checks, eventos t0/td/tr, CSV de cliente, logs y conclusión. Usa `guides/criterios.md`. No subas contraseñas, DSRM, claves privadas, ISO/MSI, discos virtuales ni PDFs de terceros.
