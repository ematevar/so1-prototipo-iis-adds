EN TU EQUIPO

Tres servidores.
Un solo comando.

Con Python 3.10 o superior, desde la raíz del repositorio:

python demo/server.py

Abre http://127.0.0.1:8080. Podrás detener un backend, esperar la detección y enviar solicitudes al superviviente.

Sin paquetes externos. El servidor sólo escucha en loopback. La prueba no modifica VirtualBox ni Windows Server.
